# SDK Packages

This folder contains the language-specific TinyHumans SDKs.

| Package | Status | Notes |
| --- | --- | --- |
| [`typescript/`](typescript/README.md) | Supported | Includes the `tinyhumans` CLI |
| [`python/`](python/README.md) | Supported | Sync stdlib HTTP client |
| [`rust/`](rust/README.md) | Supported | Async `reqwest` client |

All packages should follow the shared namespace manifest in
[`../api/tinyhumans.backend.json`](../api/tinyhumans.backend.json).
